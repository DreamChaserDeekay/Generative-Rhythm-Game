# 난이도 판: 채보가 만들어졌는지 한눈에 (전후)

곡 선택 화면에서 난이도 판의 채보가 바로 플레이할 수 있는 것인지, 아직 만들어야 하는 것인지를 보여 줍니다. 색에만 기대지 않고 **판의 테두리**, **레벨 숫자의 모양**, **짧은 낱말**로 구별합니다.

| 상태 | 판 | 레벨 숫자 | 낱말 | 고른 판 |
|---|---|---|---|---|
| 만들어짐 | 지금처럼 꽉 찬 판 | 꽉 찬 숫자 | 없음(기록이 있으면 램프) | 난이도 색으로 꽉 참 |
| 아직 안 만듦 | 점선 테두리 | 속이 빈 숫자(모델이 노리는 레벨) | 미생성 | 난이도 색 줄무늬 |
| 만드는 중 | 점선 테두리 | 속이 빈 숫자 | 생성 중(판 아래로 막대가 오감) | 난이도 색 줄무늬 |
| 차례를 기다림 | 아직 안 만듦과 같음("대기"는 쓰지 않기로 한 결정을 따름) | | 미생성 | |
| 만들기 실패 | 빨간 점선 테두리 | – | 실패 | 어두운 빨강 |
| 가져온·편집한 채보 | 원래대로 다섯 판 뒤의 따로 된 판(형식 · 이름 · 추정 레벨) | | | |

곡 목록의 줄은 지금 고른 난이도의 레벨만 보여 줍니다. 그 채보가 아직 없으면 숫자가 속이 비어 보입니다. 곡을 한 번 커서에 올려야 그 곡의 채보 정보를 알 수 있습니다.

- `before/`: develop(89e68ea)
- `after/`: 이 브랜치
- `compare.png`: 판 줄과 곡 목록을 잘라 나란히 놓은 그림
- 파일 이름은 고른 난이도와 그 상태입니다: 1 EXPERT 미생성, 2 NORMAL 만들어짐, 3 HARD 생성 중, 4 ELITE 실패, 5 MASTER 차례 기다림.

## 찍은 방법

이 환경에는 GPU가 없어 채보를 만들 수 없습니다. 그래서 `client/e2e/chartStates.ts`가 서버의 응답을 흉내 내 세 곡을 만듭니다.

- Five States: NORMAL 만들어짐(기록 HARD CLEAR), HARD 만드는 중, EXPERT 안 만듦, ELITE 실패, MASTER 차례 기다림, 가져온 osu!mania 채보 하나
- All Made: 다섯 난이도 모두 만들어짐
- None Made: 하나도 안 만들어짐
