# 곡 시작 연출: 재킷이 곡 정보판으로 (전후)

로딩 카드가 플레이에 자리를 내줄 때(0.7초) 카드의 재킷이 가는 곳입니다.

- `before/`: develop(ac21c66)의 동작입니다. 재킷이 트랙의 먼 끝(화면 위 가운데)으로 작아지며 사라집니다.
- `after/`: 이 브랜치의 동작입니다. 재킷이 플레이 화면 왼쪽 위 곡 정보판의 재킷(`.hud-jacket`, 720p에서 48px)으로 날아가 위치·크기·모서리까지 그 자리에 정확히 맞춰 내려앉습니다. 날아오는 동안 정보판의 재킷은 숨어 있고, 도착하는 순간 정보판의 재킷이 이어받습니다. 그래서 그림이 두 장 겹치지 않습니다.
- `compare.png`: 두 동작을 나란히 놓은 그림입니다.

## 찍은 방법

- 데모 곡에 표본 커버(`public/covers/c7b45c868634e2eb.jpg`)를 붙이고 4K 오토 플레이로 찍었습니다. 채보는 테스트가 건넨 단순한 채보입니다. 이 환경에는 GPU가 없어 채보를 만들 수 없기 때문입니다.
- 카드의 애니메이션만 0 · 175 · 350 · 525 · 699ms에 멈춰 찍었습니다. 그 아래의 플레이(카메라 진입, 레인 점등)는 실제 시간대로 흐르므로, 같은 칸의 트랙 모습은 전후가 조금 다를 수 있습니다.
- `landed.png`는 애니메이션을 끝까지 돌린 뒤의 모습입니다.
- 커버가 없는 곡(원판 그림)이 정보판 재킷에 1.5px 안으로 맞는 것은 `client/e2e/transitions.spec.ts`가 확인합니다.
