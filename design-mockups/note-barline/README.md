# 정박 노트와 마디선 (2026-11-19)

노트는 트랙 위에 놓인 그림과 그 아래로 늘어진 벽(두께)으로 그려진다. 예전에는 그림만 박자에 가운데를 맞춰서, 벽까지 합친 노트 전체가 마디선 아래로 처져 보였다(마디선이 노트의 위에서 약 34% 지점을 지남). 이제 노트를 벽 두께의 절반만큼 띄워, 그림과 벽을 합친 노트 전체의 가운데가 박자에 온다. 마디선과 판정선이 노트 한가운데를 지난다(48–54%).

- 기준: DJMAX RESPECT V v492(2020-06-18) 이후 "판정선의 중앙과 노트의 중앙이 만날 때 MAX 100%". EZ2ON REBOOT : R은 노트의 아래쪽 끝이 기준이다(마디선이 노트 바로 아래). 이 게임의 판정은 노트 가운데 기준이라 DJMAX를 따랐다.
