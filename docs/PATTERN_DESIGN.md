# 패턴 생성 설계

상태: **구현됨**(생성기 0.4.0, P0–P5). 생성기의 소리 고르기·밀도·레벨 맞추기는 그대로 두고, 노트를 **어느 레인에 어떤 모양으로** 놓는지를 다시 설계했다. 1–10장은 설계 당시의 글이고, 구현하면서 바꾼 점과 측정 결과는 11장에 있다. 동작 요약은 `docs/GENERATION.md` 9장, 난이도 기준(DJMAX · EZ2ON)은 같은 문서의 8장.

## 1. 지금 채보 진단

합성 곡 2개(132·165 BPM, 112·113초)로 키 모드·난이도별 채보를 만들어 레인 패턴을 쟀다. "빠른 단타"는 260ms 이하 간격으로 이어지는 단타다.

| 문제 | 측정 | 왜 문제인가 |
|---|---|---|
| 패드로 칠 수 없는 동치가 DJMAX NM–MX에 나옴 | 6K HD 41개, MX 96개(두 곡 3분 45초, MX는 2.3초에 하나). 5K MX의 1+3+5 13개 | 실제 DJMAX에서는 SC에만 나오는 배치다 |
| 낮은 난이도의 큰 도약 | 빠른 단타 이동 중 3칸 이상 도약: 8K NM 50%, 6K NM 31%. 계단은 4–6% | Lv.6 채보가 건반 전체를 뛰어다녀 읽기 어렵다 |
| 높은 난이도의 단조로움 | 빠른 단타의 3연속 이동 모양 중 가장 흔한 것의 비율: SC·SHD 7–54%(5K SHD 54%, 8K SC 34%, 6K SHD 23%), 그 아래 난이도 3–10% | 같은 모양만 되풀이된다. (구현 중 확인: SC·SHD는 동치가 많아 단타 줄기가 짧고, 한 곡에 모양 표본이 몇 개뿐이라 이 비율은 크게 과장됐다. 11장 참고) |
| 동치 모양에 규칙이 없음 | 6K 2개 동치의 51–59%가 대칭(1+6 · 2+5 · 3+4)도 이웃(1+2 …)도 아닌 모양. 8K NM 동치가 1+8까지 벌어짐 | 강세의 성격(넓은 킥+크래시, 좁은 화음)이 모양에 드러나지 않는다 |
| 트릴·계단이 우연히만 생김 | 트릴: 6K 0–9%, 8K 0–1%, 4K 1–24% | 음악이 트릴·계단을 원해도 보장되지 않는다 |

실제 채보 일부(레인 번호, `+`는 동치):

- 8K DJMAX NM Lv.6, 8분음표(165 BPM): `3 5 6 2 3 5 8 4+7 1 5 7 2+6 1 5 3 6 7 8 1 2 5 7 3 2+8`. 거의 한 음마다 건반 반대편으로 뛴다.
- 5K EZ2ON SHD Lv.16, 16분음표: `2 1+5 3 1+2+5 4 2+5 1 2+5 3 1+2+5 3 2+5 4 1+5`. 바깥 동치와 가운데 단타가 기계적으로 번갈아 나온다.

원인:

- **배치를 노트 하나씩 정한다.** 음높이 순위를 건반 전체 폭에 옮기고(높은 음 = 오른쪽), 연타·손 번갈이·사용 균형 비용을 더해 빔 서치로 고른다. 악구 단위의 "모양"이라는 개념이 없다.
- **배치 방식이 모든 난이도에서 같다.** 난이도마다 바뀌는 건 개수(밀도·동치 수·롱노트 수)와 한계(동치 크기·한 손 동시 수·연타 간격)뿐이다.
- **동치 모양은 "양손에 퍼지게"만 고른다.**
- 덤으로 찾은 것:
  - 난이도 이름에 거는 규칙 두 개가 DJMAX·EZ2ON 난이도(NM·EZ)에는 적용되지 않는다. 하나는 "EASY는 강박에만 동치", 다른 하나는 "EASY·NORMAL은 롱노트 끝을 반 박 단위로"다.
  - BMS 내보내기의 `#DIFFICULTY`가 NM·MX 같은 이름을 몰라 3(HYPER)으로 적힌다.

## 2. 패턴 디자이너의 원칙

1. **음악이 먼저다.** 패턴은 소리의 몸짓에서 나온다. 음계는 계단, 두 음 왕복과 드럼 롤은 트릴, 강세는 동치, 지속음은 롱노트가 된다. 음악에 없는 모양은 만들지 않는다.
2. **같은 소리는 같은 자리.** 한 구간 안에서 같은 악기·같은 음은 같은 레인에 둔다. 그래야 외울 수 있고, 키음이 손에 붙는다. 노트별 키음을 켜면 레인마다 제 소리가 있는 느낌이 된다.
3. **같은 음악은 같은 패턴.** 반복 구간은 같은 모양으로 둔다. 높은 난이도는 좌우 반전으로 변주한다.
4. **읽히는 단위.** 패턴은 작은 단위(셀)의 반복으로 이뤄진다. 한 박짜리 모양이 네 번 되풀이되면 읽히고, 매번 다르면 읽히지 않는다.
5. **손이 편해야 한다.** 빠를수록 양손을 번갈아 쓰고, 약한 손가락(약지·새끼)에는 덜 맡긴다. 한 손 안의 큰 도약과 벌어진 동치는 높은 난이도에서만 쓴다.
6. **난이도는 어휘로 오른다.** 밀도만이 아니라 어떤 패턴을 쓰느냐가 난이도다.
   - NM: 단타 이동·짧은 계단
   - HD: 트릴·롱잡
   - MX: 긴 계단·동치 섞인 흐름
   - SC·SHD: 겹계단·동치 연타
7. **흐름이 있다.** 절보다 후렴이 어렵고, 빌드업은 점점 어려워지고, 어려운 악구 뒤에는 숨 쉴 곳을 둔다. 곡 첫머리는 손을 푸는 정도로 쉽게 하고, 마지막 후렴을 가장 어렵게 둔다. 끝은 강세 동치나 롱노트로 맺는다.
8. **그 게임다워야 한다.** DJMAX는 NM–MX를 패드로 칠 수 있게 두고 키 모드별 관용구를 쓴다. EZ2ON은 모든 소리를 연주하는 빽빽한 흐름으로 간다.

## 3. 패턴 어휘

모양은 6K 기준이다. "처음 쓰는 난이도"는 대략 그 정도 어려움부터 쓴다는 뜻이고, 실제로는 6-2절의 단계값으로 거른다.

| 패턴 | 모양 | 음악 | 처음 쓰는 난이도 (DJMAX / EZ2ON) | 메모 |
|---|---|---|---|---|
| 단타 이동 | `3 4 3 2` | 선율의 순차 진행 | NM / EZ | 기본 재료 |
| 계단 | `1 2 3 4`, `6 5 4 3` | 상행·하행 선율, 드럼 필 | NM(3–4개) / EZ | 난이도에 따라 길어짐 |
| 손 번갈이 | `2 5 2 5` | 빠른 같은 음 반복, 8분 하이햇 | NM / EZ | 가장 쉬운 빠른 패턴 |
| 롤 | `1 2 3 1 2 3`, `1 2 3 4 3 2` | 되풀이되는 분산화음 | HD / NM | |
| 트릴 | `2 3 2 3` | 두 음 왕복, 드럼 롤 | HD / NM | 중지·약지 트릴(중약)은 SC / SHD |
| 꺾인 계단 | `1 3 2 4 3 5` | 음형을 높이만 바꿔 되풀이(시퀀스) | MX / HD | |
| 앵커 | `1 2 1 3 1 4` | 페달음 위 선율 | MX / HD | |
| 연타 | `3 3 3` | 같은 음 반복(느린) | MX / HD | 연타 간격 한계를 지킴. DJMAX 4K 고레벨에 많음 |
| 강세 동치 | `1+6`, `2+5`, `3+4` | 킥+크래시, 강박 | NM(2개, 강박만) / EZ | 모양은 소리로: 저역+고역은 넓게, 중역은 좁게 |
| 동치 섞인 흐름 | `1 2+5 3 1+6 4` | 빽빽한 리듬 + 강세 | MX / HD | EZ2ON 상위 난이도의 기본 질감 |
| 롱잡 | `1`(롱) + `4 5 6` | 지속음 + 선율 | HD / NM | 롱노트를 잡은 손은 쉬고, 다른 손이 선율 |
| 대화 | 왼손 `1 2 3` → 오른손 `6 5 4` | 주고받는 악구, 같은 악구를 다른 악기로 | HD / NM | 거울 모양 |
| 겹계단 | `1+2 2+3 3+4`, `1+3 2+4 3+5` | 병행 화음, 강한 상행 | SC / SHD | |
| 동치 연타 | `2+5 2+5` | 되풀이되는 강세 | SC / SHD | |
| 레이저 | 가운데 `3 3 3 3`(양손) | DJMAX 5B 관용구 | DJMAX 5K HD부터 | 가운데 레인에 키를 두 개 지정하는 입력 기능이 먼저 필요 |

## 4. 음악 → 패턴

1. **악구 나누기.**
   - 마디 단위로 나눈다. 빠르고 빽빽한 곳은 반 마디 단위다.
   - 1박 넘는 쉼, 구간 경계, 주 악기가 바뀌는 곳에서 끊는다.
   - 한 악구가 노트 4–16개가 되도록 합치거나 나눈다.
2. **몸짓 분류.** 분석에 이미 있는 음높이·주 스템·지속음·강세·간격으로 판단한다.

   | 몸짓 | 판단 | 어울리는 패턴 |
   |---|---|---|
   | 상행·하행 | 음높이 변화의 70% 이상이 같은 방향, 대부분 4반음 이하 | 계단(방향 = 음의 방향), 길면 롤 |
   | 왕복 | 두 음을 번갈아 | 트릴(느리거나 낮은 단계면 손 번갈이) |
   | 반복음 | 같은 음이 이어짐 | 느리면 연타, 빠르면 손 번갈이, DJMAX 5K는 레이저 |
   | 분산화음 | 같은 방향으로 뛰었다가 되돌아옴 | 롤, 꺾인 계단 |
   | 페달 | 한 음이 한 칸 걸러 반복 | 앵커 |
   | 드럼 리듬 | 주 스템이 드럼 | 소리별 고정 자리(킥·스네어·하이햇). 필은 계단·트릴 |
   | 지속음 + 선율 | 롱노트 후보 + 다른 소리 | 롱잡 |
   | 강세 | 강박의 강한 타격 | 강세 동치(모양은 대역으로) |
   | 주고받기 | 앞 악구와 리듬·모양이 같고 음역·악기만 다름 | 대화(거울) |

3. **음높이와 패턴의 역할 분담.** 음높이는 어디서 시작해 어느 쪽으로 가는지를 정하고, 패턴은 어떤 모양인지를 정한다. 높은 선율은 오른쪽에서 시작하고, 상행이면 오른쪽으로 계단을 탄다.

예: 같은 한 마디를 난이도별로 배치한 결과(6K). 음악은 선율 8분 "도 레 미 레 | 도 레 미 −", 킥 1·3박, 스네어 2·4박, 하이햇 엇박이다.

| 난이도 | 배치 | 쓴 패턴 |
|---|---|---|
| DJMAX NM | `1+4 5 6 5 4 5 6` | 선율만 오른손 계단, 1박에만 킥 강세 동치(킥은 늘 `1`) |
| DJMAX MX | `1+4 5 2+6 5 1+4 5 2+6` | 손 분담: 왼손 킥 `1`·스네어 `2`, 오른손 선율 롤 |
| EZ2ON HD | `1+4 3+5 2+6 3+5 1+4 3+5 2+6` | 모든 소리: 하이햇 `3`까지, 왼손이 드럼 그루브 |

## 5. 게임·키 모드별 스타일

**DJMAX**

- 선율 중심이다. 계단·롤로 선율을 그리고, 드럼은 강세 동치와 고정 자리로 둔다.
- 패드 규칙(NM · HD · MX): 한 손의 떨어진 두 키를 동시에 누르는 동치를 금지한다. 6K 1+3 · 4+6, 5K 1+3+5가 그렇다(나무위키가 SC 전용 배치의 예로 든 것). SC에서만 허용한다.
- 키 모드별 특징(나무위키 시스템 문서):
  - 4B(4K): 라인이 적어 노트 수를 늘리기 어렵고, 고레벨은 연타 같은 피지컬 요소가 많다
  - 5B(5K): 가운데 레인을 어느 손으로 칠지 바뀌는 배치와 레이저
  - 8B(8K): "뇌지컬"(머리를 쓰는 복잡한 배치)이 특징이다. 그래서 상위 단계에서 손 분담을 강하게 쓴다
  - FX: 본편 사이드 노트는 모두 롱노트
- 설계 선택: 6B(6K)는 한 레인에 키 하나라 직관적인 모드다. 양손 대칭 동치와 거울 모양을 많이 쓴다.
- SC: 키보드 전용 모양(1+3, 1+3+5, 4개 동치), 겹계단, 중약 트릴, 32분 연타.

**EZ2ON**

- 모든 소리를 노트로 쓴다. 레이어를 모두 따라가고, 같은 소리는 곡 내내 같은 자리(악기별 집)에 둔다.
- 처리량 위주의 동치 섞인 흐름이다. 앵커·꺾인 계단 같은 까다로운 모양은 덜 쓴다.
- 8K는 3–4개 동치의 비중이 높다.

**기본**

지금의 생성 스타일 7종(균형·스트림·동치·연타·롱노트·테크니컬·멜로디)을 어휘 가중치로 옮긴다. 예를 들어 스트림은 계단·롤, 연타는 연타·동치 연타, 멜로디는 계단·대화 쪽으로 기운다.

## 6. 알고리즘

### 6-1. 전체 흐름

```
분석 + 노트 고르기 (지금 그대로: 어떤 소리를 노트로, 동치 크기, 롱노트, 사이드·스크래치)
  │
  ├─ ① 역할·자리 계획 (구간마다): 레이어 → 손·영역, 소리별 고정 자리
  ├─ ② 악구 나누기 + 몸짓 분류
  ├─ ③ 패턴 고르기 (악구 열 전체를 동적 계획법으로)
  ├─ ④ 배치 (빔 서치: 패턴 목표 + 손가락 모델 + 제약)
  └─ ⑤ 검사·측정 (린터 + 패턴 지표) → 지금의 레벨 맞추기 루프로
```

### 6-2. ① 역할·자리 계획

- **단계값(0–1).** 목표 유효 NPS를 기본 기준 레벨 표에 대응시켜 얻는다. 기준(DJMAX · EZ2ON · 기본)이 달라도 어려움이 같으면 단계값이 같다. 난이도 이름에 걸던 규칙도 이 값으로 바꾼다.
- **단계값에 따른 영역:**
  - 0.35 미만(초급): 한 번에 한 레이어만 따라간다. 활성 창은 연속된 레인 몇 칸(6K 4칸, 8K 4–5칸, 4K·5K는 전부)이고, 악구가 바뀔 때 음역을 따라 천천히 옮긴다.
  - 0.35–0.7(중·상급): 선율은 건반의 2/3쯤, 드럼·베이스 강세는 반대쪽에 둔다. 롱잡은 손을 나눈다.
  - 0.7 이상(최상급): 손 분담(왼손 리듬·오른손 선율)을 쓰고 건반 전체를 쓴다. 분담은 구간마다 바꾸거나, 반복 때 거울로 뒤집는다.
- **소리별 고정 자리.** 슬롯을 소리 정체(주 스템 + 대역 모양, 음높이가 있으면 음 이름)로 묶고, 같은 소리가 같은 레인에서 벗어나면 비용을 매긴다.
  - EZ2ON 스타일은 곡 전체에서, DJMAX는 구간 안에서 지킨다.
  - 단계값이 높을수록 느슨하게 둔다.

### 6-3. ② 악구 나누기·몸짓 분류

4장의 규칙대로 나누고 분류한다. 악구마다 다음 정보를 남긴다:

- 몸짓
- 주 레이어
- 셀(리듬이 같은 작은 단위)
- 강세 위치
- 지속음
- 구간 에너지

### 6-4. ③ 패턴 고르기

```
각 악구 p:
    후보 = [m for m in 어휘 if 단계값 ≥ m.시작 단계 and 스타일[기준].허용(m, 키 모드)]
    점수(p, m) = 적합도(m, p.몸짓) × 스타일 가중치[기준][m] − 복잡도 초과(p, m)
전이(이전, m) = − 다양성 벌점 (다른 음악인데 같은 패턴이 이어질수록 커짐)
                + 일관성 보너스 (같은 반복 묶음이면 같은 패턴, 높은 단계는 거울)
최적 = 비터비(악구 열, 점수, 전이)
```

- **구간 주제.** 악구를 고르기 전에 구간마다 주된 패턴 1–2개를 정한다. 예를 들어 절은 선율 계단, 후렴은 동치 섞인 흐름, 브리지는 롱잡이다. 악구는 주제 안에서 먼저 고르므로 구간마다 성격이 생긴다. 같은 반복 묶음의 구간은 같은 주제를 쓴다.
- **복잡도 예산** = 단계값 × 구간 에너지. 후렴·드롭이 크고 절이 작다. 어려운 악구 다음 악구는 예산을 줄이고, 곡 첫 악구들은 예산을 낮게 시작한다.
- **결과:** 악구마다 패턴, 방향, 손·영역, 셀 길이가 정해진다.

### 6-5. ④ 배치

지금의 빔 서치(제약·롱노트·사이드·스크래치·반복 구간 처리)는 그대로 두고, 비용 항을 바꾼다.

- **패턴 목표.** 악구의 패턴이 노트마다 기대 위치를 준다. 어긋나면 비용을 매긴다(한 칸 차이는 절반).

  | 패턴 | 기대 위치 |
  |---|---|
  | 계단 | 앞 노트 ±1(끝에서는 되돌거나 감김) |
  | 트릴 | 정해 둔 두 레인을 번갈아 |
  | 손 번갈이 | 양손의 짝 레인 |
  | 앵커 | 한 칸 걸러 앵커 레인 |
  | 강세 동치 | 동치 모양 목록 중 하나 |
  | 겹계단 | 동치 전체가 ±1 |

- **시작 위치와 방향.** 음높이로 정한다(음역 → 위치, 음의 방향 → 이동 방향).
- **셀 반복.** 악구 안에서 리듬이 같은 셀은 첫 셀의 레인을 목표로 삼는다. 지금의 반복 구간 일관성과 같은 방식을 작은 범위에 쓴다.
- **동치 모양 어휘.** 키 모드별 모양 목록을 둔다: 이웃, 대칭, 벌어짐, 3개, 4개.
  - 단계와 기준에 따라 쓸 수 있는 모양을 제한한다.
  - 소리 대역으로 고른다: 저역+고역은 넓게, 중역은 좁게.
- **결정성과 속도.** 같은 시드면 같은 채보가 나온다. 생성 시간은 지금(곡당 1–2초)과 비슷하게 둔다. 계획 단계는 악구 수에 비례하는 가벼운 계산이다.

### 6-6. 손가락 모델과 제약

- **손가락 힘.** `config/keymodes.json`의 손가락 번호를 쓴다: 엄지 0.9, 검지 1.0, 중지 0.95, 약지 0.8, 새끼 0.65.
- **비용:**
  - 빠른 구간에서 약한 손가락에 몰리는 부담
  - 약한 손가락끼리의 트릴(중지·약지, 약지·새끼). 최상급에서만 허용한다.
  - 한 손 안의 2칸 이상 도약과 벌어진 동치. 단계값에 따라 비용을 매긴다.
  - 빠를수록 양손 번갈이를 보상한다(지금도 있음).
- **패드 규칙.** DJMAX NM · HD · MX에서는 하드 제약이다. 동치 조합 후보에서 빼고, 린터도 검사한다.
- **초급 도약 제한.** 빠른 단타의 3칸 이상 도약에 큰 비용을 매긴다.

## 7. 난이도와의 관계

- 3장의 어휘가 난이도의 질을 정하고, 밀도와 레벨 맞추기는 지금처럼 한다.
- 배치가 바뀌면 난이도 산정기의 유효 NPS(손 부담)가 달라진다. 그래서 레벨 표 맞추기(채보 1,575개)와 확인(96개, `GENERATION.md` 8-2·8-4)을 다시 한다.
- 난이도 산정기에 패턴 부담을 넣을지 검토한다: 트릴, 꺾인 계단, 동치 연타, 한 손 도약.

## 8. 확인 방법

- **패턴 지표.** 이번 측정 도구를 서버 모듈로 옮긴다. 재는 것:
  - 계단·트릴·연타 비율
  - 도약(같은 손 / 다른 손)과 손 번갈이
  - 동치 모양 분포, 패드로 칠 수 없는 동치, 약한 손가락 트릴
  - 모양 다양성(가장 흔한 모양의 비율)과 손가락별 부담
  - 양손 균형(지금의 `handLoad`, 의도한 손 분담이 아니면 40–60%)
- **처음 목표**(조정 가능):

  | 지표 | 목표 | 지금 |
  |---|---|---|
  | 패드로 칠 수 없는 동치 (DJMAX NM–MX) | 0 | 6K MX 96개 |
  | 초급의 빠른 단타 3칸 이상 도약 | 6K 10%, 8K 15% 이하 | 31%, 50% |
  | 가장 흔한 3연속 이동 모양 비율 (모든 단계) | 20% 이하 | 최대 54% |
  | 상행 음계 → 상행 계단 | 해당 이동의 80% 이상 | 보장 안 됨 |
  | 반복 구간 일관성 | 지금 수준 유지 | 0.98–0.99 |

- **테스트용 합성 곡.** 음계·왕복·페달·분산화음·드럼 필이 들어간 악구를 일부러 넣은 곡을 만들어, 몸짓 → 패턴 대응을 pytest로 확인한다.
- **비교 플레이.** 생성 옵션에 "패턴 엔진: 새 / 이전"을 당분간 둔다. 같은 곡을 번갈아 쳐 보며 비교한다.
- **채보 정보 표시.** "패턴 성향"(계단·트릴·동치·연타·롱잡 비율)을 보여 준다.

## 10. 한계와 열어 둔 질문

- **실제 패턴 빈도를 맞출 데이터가 없다.** DJMAX·EZ2ON 실제 채보의 패턴 빈도는 공개 데이터가 없다. 공개 지표(MULTI · LONG · SIDE · JACK · CLIMAX), 공개 설명, 이 문서의 원칙으로 시작하고, 플레이 피드백으로 고친다. 채보 자체는 쓰지 않는다.
- **합성 곡은 실제 곡보다 단순하다.** 몸짓 분류는 실제 곡(사용자 곡)으로도 확인해야 한다.
- **패턴 취향은 사람마다 다르다.** 어휘 가중치를 `config/patterns.json`과 생성 옵션으로 열어 둔다.
- **(나중에) 개인 스타일.** 사용자가 가져온 자기 채보(BMS · osu!)에서 패턴 통계를 뽑아 개인 스타일로 쓸 수 있다. 사용자 PC 안에서만 하고, 다른 게임의 채보를 내장하지 않는다.
- **레이저는 입력 기능이 먼저다.** 가운데 레인에 키 두 개를 지정할 수 있어야 한다.

## 11. 구현 결과

### 11-1. 설계에서 바꾼 점

- **모양과 질감을 나눴다.** 처음 설계는 "강세 동치·롱잡·동치 섞인 흐름"도 모양의 하나로 골랐다. 그러자 그 악구의 단타가 아무 모양도 따르지 않았다. 지금은 악구마다 단타의 모양(계단·트릴 …) 하나와, 동치의 질감(바꾸기·겹계단·동치 연타)·롱잡 여부를 따로 정한다. 모양은 사이에 동치가 끼어도 단타끼리 이어진다.
- **단계값은 레벨 숫자로 정한다.** 유효 NPS를 기본 척도에 대응시키면 같은 DJMAX NM Lv.5가 4K에서는 0.44, 8K에서는 0.22가 됐다. 기본 척도가 넓은 키 모드에 다른 배율을 쓰기 때문이다. DJMAX·EZ2ON은 레벨 15까지 레벨별 밀도가 거의 같고 기본 기준도 같은 레벨 숫자를 쓰므로, 레벨 숫자를 한 척도로 본다. DJMAX SC는 DJ POWER 상수(SC 2·4·6·8 = 12·13·14·15)로 옮긴다.
- **재는 방법을 고쳤다.**
  - 계단·트릴·다양성은 400ms 이하로 이어지는 단타 줄기에서 잰다(165 BPM의 8분음표 흐름이 260ms 기준에서는 빠져 있었다). 도약과 손 번갈이는 260ms 이하의 빠른 이동만 센다.
  - 다양성(가장 흔한 모양의 비율)은 모양 표본이 20개 이상일 때만 낸다. 1장의 "SC·SHD 최대 54%"는 동치가 많아 한 곡에 표본이 몇 개뿐이던 값이라 크게 과장됐다.
- **패턴 판단을 다듬었다.**
  - 대화(주고받기)는 리듬만이 아니라 선율 모양까지 같은 두 반쪽일 때만 쓴다. 고르게 이어지는 8분음표 악구가 전부 대화로 잡히던 것을 고쳤다.
  - 앵커는 악구의 첫 음이 아니라 가장 많이 반복되는 음(페달)을 고정한다.
  - 몸짓 판단에는 동치에 얹힌 선율 음도 넣는다.
  - 분산화음은 올라갔다 내려오는 모양도 잡는다.
- **5K 가운데 키 처리.** 가운데 키는 거울이 자기 자신이라, 손 번갈이의 짝을 이웃 키로 정한다. 레이저는 입력 기능을 바꾸지 않고, Space를 양손 엄지로 번갈아 칠 수 있다고 보고 가운데 키만 150ms까지 반복을 허용했다.
- **역할과 모양을 맞췄다.** 리듬과 선율이 같이 있는 악구에서는 모양을 선율 음끼리만 따지고, 드럼은 자기 키를 지킨다. 모양은 역할 영역(그 손) 끝에서 꺾인다.

### 11-2. 측정

같은 합성 곡 2개(132·165 BPM)에서, 이전 방식(`patternEngine: "classic"`) → 패턴 엔진. 이전 방식에도 P0의 패드 규칙·단계값 규칙과 다시 맞춘 레벨 표가 들어가 있다.

| 채보 | 빠른 도약(3칸 이상) | 계단 | 트릴 | 레벨(두 곡) |
|---|---|---|---|---|
| 6K 기본 NORMAL | 38% → 1% | 12% → 9% | 5% → 10% | 6·5 → 6·6 |
| 8K 기본 NORMAL | 43% → 3% | 5% → 21% | 0% → 17% | 5·6 → 5·6 |
| 5K 기본 NORMAL | 20% → 3% | 10% → 12% | 5% → 10% | 6·6 → 6·6 |
| 8K DJMAX NM Lv.6 | 51% → 11% | 7% → 14% | 0% → 2% | 6·6 → 6·6 |
| 6K EZ2ON EZ Lv.5 | 27% → 5% | 12% → 22% | 2% → 11% | 5·5 → 5·5 |
| 8K EZ2ON EZ Lv.5 | 46% → 11% | 7% → 19% | 2% → 19% | 4·5 → 5·5 |
| 6K DJMAX HD Lv.9 | 30% → 11% | 10% → 12% | 1% → 4% | 10·9 → 8·9 |
| 8K DJMAX HD Lv.9 | 43% → 15% | 6% → 16% | 0% → 4% | 10·9 → 9·9 |
| 6K DJMAX MX Lv.13 | 34% → 21% | 3% → 5% | 1% → 3% | 13·13 → 13·13 |
| 6K EZ2ON SHD Lv.16 | 37% → 48% | 0% → 0% | 2% → 1% | 15·15 → 16·15 |

- **DJMAX NM–MX의 패드로 칠 수 없는 동치**는 두 방식 모두 0이다(P0부터). 패턴 엔진 전 측정에서는 6K MX에 두 곡 96개였다.
- **최상급의 도약 증가.** EZ2ON HARD·SUPER HARD는 손 분담(리듬 한 손, 선율 다른 손) 때문에 도약이 늘었다. 대부분은 양손을 오가는 이동이지만, 선율이 한 손 안에 모이면서 같은 손 안의 두 칸 이동도 늘었다(빠른 이동 중 6K HD 4% → 19%, 6K SHD 3% → 14%, 8K HD 9% → 21%). 낮은·중간 단계에서는 같은 손 도약이 크게 줄었다(8K NORMAL 28% → 3%, 6K EZ2ON EZ 23% → 3%). 최상급이 손에 너무 꼬이면 `config/patterns.json`의 `roles.handSplitSkill`(8K는 `handSplitSkill8K`)을 올려 손 분담을 늦춘다. 같은 손 도약 비용(`weights.sameHandLeap`)은 단계값이 1에 가까울수록 약해지므로 최상급에는 거의 듣지 않는다.
- **손으로 만든 몸짓 곡**(`tests/test_patterns.py`, 모든 소리를 노트로):
  - 음계는 한 칸씩 움직이는 이동이 85% 이상이다.
  - 두 음 왕복은 두 레인 트릴이 된다(이전 방식은 흩어짐).
  - 같은 음 반복은 번갈이가 된다(이전 방식은 연타).
  - 페달은 앵커가 되고, 드럼은 소리마다 같은 키를 쓴다.
  - DJMAX 5K 반복음은 가운데 키 연속 5개 이상(레이저)이 된다.
  - 어려운 채보는 드럼·선율의 85% 이상을 다른 손에 둔다. DJMAX는 반복 묶음마다 좌우를 바꾸고, EZ2ON은 킥이 곡 내내 같은 키다.
- **레벨 표.** 다시 맞춘 레벨 표로 DJMAX 48개 채보가 모두 목표 ±1이다(`GENERATION.md` 8-4).
- **생성 시간**은 평균 2배로 늘었다(채보 대부분 1.3–2.7배). 가장 느린 8K MASTER가 곡당 약 2.3초다.

### 11-3. 남은 한계

- **합성 곡이 단순하다.** 합성 곡의 선율은 무작위 5음 음계라, 몸짓이 대부분 "자유"나 "리듬"으로 잡힌다. 실제 곡에서 어떻게 느껴지는지는 집에서 이전 방식과 번갈아 쳐 보며 확인해야 한다.
- **최상급은 단타 모양이 들어갈 자리가 적다.** SC·SHD는 노트의 2/3 이상이 동치라, 동치 질감(겹계단·동치 연타)이 주로 일한다.
- **실제 채보와 비교하지 못했다.** 실제 DJMAX·EZ2ON 채보의 패턴 빈도는 공개 데이터가 없어 맞춰 보지 못했다. 목표와 가중치(`config/patterns.json`)는 플레이 피드백으로 고친다.
