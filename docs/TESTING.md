# 집에서 테스트하기 (Windows)

Windows PC에 설치 파일로 설치해서 처음부터 끝까지 확인하는 순서입니다. 전부 하면 40분쯤 걸립니다. 각 단계에 **기대 결과**를 적어 두었으니, 다르게 나오면 그 단계 번호와 함께 알려 주세요.

![Windows에 설치한 앱 (GitHub Actions의 Windows 머신에서 설치 후 찍은 화면)](screenshots/13-windows-app.png)

## 1. 설치 파일 받기

설치 파일은 GitHub Actions가 코드를 올릴 때마다 Windows 머신에서 새로 만들고, 실제로 설치·실행해 본 뒤 올려 둡니다.

1. GitHub에 로그인한 상태로 [Actions → Desktop app (Windows)](https://github.com/DreamChaserDeekay/Generative-Rhythm-Game/actions/workflows/desktop-windows.yml)를 엽니다.
2. 맨 위의 **초록색 체크**가 붙은 실행을 누릅니다.
3. 아래쪽 **Artifacts**에서 `GenerativeRhythm-Windows-Setup`을 누르면 zip(약 180MB)이 받아집니다.
   - 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 막으면 `…` → **유지**를 누르세요.
4. 압축을 풀면 `GenerativeRhythm-Setup-0.1.0.exe`가 나옵니다.

Artifacts는 30일 동안 보관됩니다. 기한이 지났거나 새로 만들고 싶으면 같은 페이지의 **Run workflow** 버튼을 누르면 5분쯤 뒤에 새 설치 파일이 생깁니다.

## 2. 설치

1. `GenerativeRhythm-Setup-0.1.0.exe`를 실행합니다.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 코드 서명 인증서가 없는 설치 파일이라 뜨는 경고입니다.
3. 언어는 **한국어**, 설치 대상은 **나만**(현재 사용자, 관리자 권한 필요 없음)을 고르고, 폴더는 그대로 두고 설치합니다.
4. 마지막 화면에서 **Generative Rhythm 실행**을 체크한 채 마칩니다. 바탕 화면과 시작 메뉴에도 바로 가기가 생깁니다.

| 항목 | 위치 |
|---|---|
| 프로그램 | `%LOCALAPPDATA%\Programs\Generative Rhythm` |
| 라이브러리(곡·채보·기록·리플레이) | `%APPDATA%\Generative Rhythm\library` |
| 분석 서버 로그 | `%APPDATA%\Generative Rhythm\server.log` |

- 탐색기 주소창에 위 경로를 그대로 붙여 넣으면 열립니다.
- 처음부터 다시 해 보려면 앱을 끄고 `library` 폴더를 지우세요.
- 지우기: 설정 → 앱 → 설치된 앱 → Generative Rhythm → 제거. `%APPDATA%\Generative Rhythm`(라이브러리)은 남으니 필요하면 직접 지우세요.
- 분석 서버는 이 PC 안(127.0.0.1)에서만 열리고, 내 음악은 PC 밖으로 나가지 않습니다. 방화벽 창이 뜨면 취소해도 됩니다.

## 3. 테스트 순서

### 3-1. 첫 실행

- [ ] 앱을 켜면 "분석 서버를 시작하는 중…" 다음에 곡 선택 화면이 나온다.
  - 기대 결과: 보통 몇 초, **첫 실행만** 백신 검사 때문에 길게는 1분쯤 걸릴 수 있습니다. 2분이 넘으면 오류 화면에 로그 위치가 나옵니다.

### 3-2. 싱크와 입력 (먼저 해 주세요)

- [ ] 오른쪽 위 **싱크 테스트**: 클릭 소리에 맞춰 오토 플레이가 돌아간다.
  - 기대 결과: 노트가 클릭 소리와 같은 순간에 판정선에 닿고, 결과가 **PERFECT PLAY · 100.00%**. 화면이 끊기지 않는다.
- [ ] **캘리브레이션**: 시작 → 메트로놈에 맞춰 아무 키나 10번 이상 → **N ms로 적용**.
  - 기대 결과: 표준편차가 30ms 안쪽. 평균 오차는 PC·이어폰마다 다릅니다(블루투스 이어폰은 100ms 넘게 나오기도 합니다).
- [ ] 설정 → 키 설정 → **동시 입력 테스트**: 7K+1S 키(왼쪽 Shift, S D F Space J K L)를 한꺼번에 눌러 본다.
  - 기대 결과: 누른 키가 모두 켜진다. 일부가 안 켜지면 키보드가 그 조합을 동시에 못 읽는 것이니 다른 키로 바꾸세요.

![캘리브레이션](screenshots/12-calibration.png)

### 3-3. 데모 곡으로 한 바퀴

- [ ] 왼쪽 **데모 곡** → 분석이 끝나면 키 모드 **4K**, 난이도 **NORMAL** → **플레이**(Enter) → 키보드로 끝까지 친다.
  - 기대 결과: 분석은 10초 안팎. 노트가 소리에 맞게 내려오고, 끝나면 결과 화면이 나온다.

### 3-4. 내 노래 (가장 중요)

- [ ] **곡 추가**를 누르거나 창에 음악 파일을 끌어다 놓는다(MP3 · M4A · AAC · FLAC · OGG · OPUS · WAV, 여러 개 가능).
  - 기대 결과: 목록에 바로 생기고 진행률이 오른다. 4분 곡이 20~30초.
- [ ] **분석 보기**: 파형 위 박자선(노란 선이 마디 첫 박)이 킥·스네어에 맞는지, BPM이 맞는지 본다.
  - 어긋나면 **BPM 보정**(×2, ÷2, 직접 입력)과 **첫 박 위치**로 고칩니다. 고치면 다시 분석하고 채보를 새로 만듭니다.
- [ ] 키 모드를 4K → 5K → 6K → 7K+1S → 8K로, 난이도를 EASY → MASTER로 바꿔 가며 채보를 만들어 본다.
  - 기대 결과: 난이도가 오를수록 노트 수·레벨이 오른다. 같은 설정이면 같은 채보, **다른 패턴**을 누르면 새 채보.
- [ ] 몇 개를 직접 플레이한다.
  - 볼 것: 노트가 소리(드럼·베이스·멜로디)에 붙어 있는지, 손이 꼬이는 배치나 너무 빽빽한 구간이 없는지, 조용한 구간은 쉬는지, 같은 후렴은 비슷한 패턴인지.
- [ ] **생성 옵션**에서 스타일(롱노트 위주, 연타 등)이나 밀도를 바꿔 다시 만들어 본다.

| 키 모드 | 기본 키 |
|---|---|
| 4K | D F J K |
| 4K+FX | 왼쪽 Shift · D F J K · 오른쪽 Shift |
| 5K | D F Space J K |
| 6K | S D F K L ; |
| 6K+FX | 왼쪽 Shift · S D F K L ; · 오른쪽 Shift |
| 7K+1S | 왼쪽 Shift(스크래치) · S D F Space J K L |
| 8K | A S D F J K L ; |

키는 설정에서 바꿀 수 있고, 한글 입력 상태여도 그대로 동작합니다.

### 3-5. 플레이 중 조작과 옵션

- [ ] 플레이 중 ↑/↓ 배속(Shift는 크게), PageUp/PageDown 위쪽 가림막(SUDDEN+), Shift+PageUp/PageDown 판정선 올리기(LIFT), Home 가림막 켜기/끄기.
- [ ] Esc 일시정지 → 계속/재시작/나가기, F2 바로 재시작.
- [ ] 곡 선택의 **플레이 옵션**: 판정 NORMAL/HARD/MAX, 게이지 HARD 이상(0%가 되면 바로 끝남), MIRROR/RANDOM, FEVER 수동(Enter로 발동).
  - 기대 결과: 바꾼 배속·가림막은 다음 플레이에도 남는다.

### 3-6. 연습 모드

- [ ] **연습 모드** 체크 → 구간(시작·끝)과 0.75배속을 고르고 플레이.
  - 기대 결과: 그 구간만 반복되고, 느려져도 음정은 그대로.

### 3-7. 결과 화면

- [ ] 판정별 개수, 게이지 그래프, 구간별 BREAK·타이밍 그래프, 타이밍 분포.
- [ ] 타이밍 분포 아래 오프셋 추천 → **적용**.
- [ ] **리플레이 보기**: 방금 플레이가 그대로 재생되고 점수가 똑같이 나온다. **리플레이 파일 저장**으로 파일도 남겨 본다.
- [ ] **osu!mania / BMS / bmson 내보내기**: 저장 창이 뜨고 파일이 저장된다(음원은 들어가지 않고 파일 이름만 적힙니다).

![결과 화면](screenshots/06-result.png)

### 3-8. 채보 에디터

- [ ] 곡 선택에서 채보를 만든 뒤 **채보 편집**.
- [ ] 클릭으로 노트 놓기, 드래그로 롱노트, 우클릭으로 지우기, Ctrl+Z 되돌리기, 휠로 이동.
- [ ] **커서부터 테스트**(T) → 플레이 → Esc → 나가기 → 에디터로 돌아오고 고친 내용이 남아 있다.
- [ ] **저장**(Ctrl+S) → 나가면 **저장된 채보**에 "편집"으로 보이고, 고르면 그 채보로 플레이된다.

### 3-9. 채보 가져오기

직접 가지고 있는 파일로 해 주세요(저작권 있는 곡은 공유하지 말고 내 PC에서만).

- [ ] **파일·압축**: osu!mania 비트맵(.osz), BMS 묶음(.zip), .bms · .bme · .bml · .bmson · .osu 파일.
- [ ] **폴더**: BMS 폴더를 통째로.
  - 기대 결과: "채보 N개를 가져왔습니다". **저장된 채보**에서 고르면 키 모드·난이도 탭이 그 채보에 맞게 바뀌고, 키음 BMS는 누르는 노트마다 그 소리가 난다(오토 플레이로 들어 보세요).

![BMS 폴더 가져오기](screenshots/09-import.png)

### 3-10. 연출과 꾸미기

- [ ] 설정 → 화면의 **카메라 연출** 세기, **배경 밝기**, **비주얼라이저**, 그리고 **스킨**(네온·클래식·모노·선셋).
- [ ] 곡 선택 화면 아래쪽(BPM 보정 아래)의 **배경 영상**에 mp4·webm을 넣고 플레이 → 배경에서 곡과 같이 재생된다.
- [ ] 설정 → 소리 → **스템 키음**을 켜고 일부러 놓쳐 본다 → 놓친 동안 노트가 따라가는 악기(보컬·멜로디 등) 소리가 작아진다.

### 3-11. 게임패드·컨트롤러 (있으면)

- [ ] 설정 → **게임패드 · 전용 컨트롤러**: 연결되면 이름이 보인다. 레인 칸을 누르고 패드 버튼(또는 턴테이블)을 움직여 지정.
- [ ] 메뉴에서 십자키 이동, A 확인, B 뒤로, Y 키 모드 바꾸기. 플레이 중 Start는 일시정지.

### 3-12. 끄고 다시 켜기

- [ ] 창을 닫은 뒤 작업 관리자에 `rhythm-server.exe`가 남아 있지 않다.
- [ ] 다시 켜면 곡·채보·기록이 그대로 있다.

## 4. 문제가 생기면

| 증상 | 해 볼 것 |
|---|---|
| "분석 서버가 종료되었습니다/응답하지 않습니다" | `server.log` 마지막 부분 확인. 백신이 `rhythm-server.exe`를 격리했으면 복원·예외 등록 후 다시 실행 |
| 화면이 안 나오거나 "WebGL" 오류 | 그래픽 드라이버 업데이트. 드라이버가 없으면 소프트웨어 렌더링으로 돌아 느릴 수 있음 |
| 소리와 노트가 안 맞음 | 캘리브레이션 → 그래도 노트가 늦게 보이면 설정의 **표시 오프셋**. 블루투스 이어폰은 지연이 커서 유선 권장. Windows 소리 설정의 "오디오 향상"을 끄면 나아지기도 함 |
| 입력이 밀림 | 전체 화면(F11), 화면 녹화·오버레이 프로그램 끄기, 모니터 주사율 확인 |
| 곡 분석 실패 | 다른 형식으로 바꿔 보기. 오류 메시지와 `server.log`를 보내 주세요 |

## 5. 알려 줄 것

- 단계 번호와 증상, 가능하면 화면 캡처(Win+Shift+S)
- `%APPDATA%\Generative Rhythm\server.log`
- 채보가 이상했다면 곡 정보(장르, BPM, 길이), 키 모드·난이도, 어느 부분인지(예: 1분 20초 후렴)
- PC 정보: Windows 버전, CPU, 그래픽 카드, 오디오 장치(유선/블루투스), 모니터 주사율
- 캘리브레이션 평균 오차와 표준편차

## 6. 설치 없이 소스로 실행하기 (선택)

[Python 3.12](https://www.python.org/downloads/)와 [Node.js 22 LTS](https://nodejs.org/)를 설치한 뒤 PowerShell에서:

```powershell
git clone -b claude/zealous-davinci-0w3s3l https://github.com/DreamChaserDeekay/Generative-Rhythm-Game.git
cd Generative-Rhythm-Game\server
py -3.12 -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
cd ..\client
npm install
npm run build
cd ..\server
.venv\Scripts\python -m rhythm_server
```

Chrome이나 Edge에서 <http://127.0.0.1:8765>를 엽니다. 이때 라이브러리는 저장소의 `data` 폴더에 생깁니다.
