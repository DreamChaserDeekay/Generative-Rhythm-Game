# 과제별 비용

`client/audit/tasks.audit.ts`가 과제마다 적어 둔 입력을 실제로 눌러, 목표에 닿았는지 확인한 뒤 센 것입니다. 원본: `data/tasks.json`.

- **입력 수**: 누른 키(버튼)의 수. 길게 눌러 반복하는 것도 한 번씩 셉니다.
- **시간(모델)**: KLM(Card·Moran·Newell)의 연산자로 셈한 추정값입니다. K = 0.28초(보통 타자 실력), 새 화면이나 새 묶음을 찾을 때마다 M = 1.35초. 패드 버튼에도 같은 K를 썼습니다(가정). **사람을 잰 값이 아닙니다.**
- **앱 응답**: 마지막 입력부터 목표 상태까지 자동 실행에서 잰 시간(이 컨테이너, 소프트웨어 렌더링).
