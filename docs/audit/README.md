3. **설정 12개가 설정 화면과 플레이 옵션 두 곳에** 다른 도움말·다른 순서로 있습니다(S1).
4. **이름 때문에 못 찾는 것이 있습니다**: "효과음"은 기본 설정에서 아무 소리도 바꾸지 않고(N1), 대리 테스트에서 "틱 소리만 줄이기"는 4명 모두 실패했습니다.
5. 패널을 연 채 설정이나 측정에 다녀오면 패널이 닫혀 있고(66번), 검색을 닫으면 포커스가 패널을 떠납니다(36번) (K2, K3).
6. 대비·글자 크기·포커스 표시는 잰 범위에서 문제가 없었습니다.

## 이 환경에서 확인하지 못한 것

- **사람**: 찾기 테스트는 서브에이전트가 대신했습니다. 빈도는 모두 추정입니다. 시간은 KLM 모델 값입니다.
- **실제 게임패드**: `client/e2e/gamepad.spec.ts`와 같은 가짜 패드(`navigator.getGamepads`를 바꿔치기)로 쟀습니다. 표준 배치 한 종류뿐이고, 스틱·비표준 패드·턴테이블은 재지 않았습니다.
- **데스크톱 앱(Electron)**: 띄우지 못했습니다. X1이 거기서도 나는지, 메뉴의 새로 고침(F4), 서버 꺼짐 화면이 뜨는 경우는 코드로만 봤습니다.
- **브라우저 버전**: 저장소가 고정한 Playwright의 Chromium이 이 환경에 없어 설치된 것(141)에 연결해 돌렸습니다. 저장소는 바꾸지 않았습니다.
- **렌더링 속도**: 소프트웨어 렌더링이라 ms 값은 실제 기기와 다릅니다.
- **화면 낭독기**, 확대(200%), 색각 이상 시뮬레이션은 하지 않았습니다.
- **빌드한 앱**: 모든 측정은 개발 서버(`vite`)에서 했습니다.
- 대비 측정은 그림 위의 글자를 재지 않습니다. `settings:fx`의 "완료" 버튼 1건은 측정 오류인지 확인하지 않았습니다.
