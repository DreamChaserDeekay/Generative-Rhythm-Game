브랜치 `claude/ui-finish`. 사용자의 2026-11-11 피드백(기타 4·5·6·7·9, 결과 화면)을 화면 쪽에서 반영한 기록입니다.

| 항목 | 내용 |
|---|---|

| 기타 4 | 난이도 판과 곡 선택의 안내 문구에서 "AI"를 지웠습니다. 아직 만들지 않은 난이도의 판은 상태 글자 없이 비어 있습니다. |
| 기타 5 | 설정의 "고급" 탭을 지웠습니다. 화면 모드 → 연출·배경(맨 위), 모두 초기화 → 플레이(맨 아래), 분석 백엔드 항목 삭제. 기존 생성기에만 쓰이던 곡 구간 편집기(`SectionEditor.tsx`)와 분석 보기의 온셋 표시도 지웠습니다. |
| 기타 6 | "AI 채보" 탭 → "채보 생성기". 상태 줄, "AI 채보 쓰기", "앱의 박자 쓰기" 줄 삭제. 설치 · 다시 설치 버튼은 탭 제목 줄 오른쪽 끝(미리보기 왼쪽)에 있고, 첫 행에서 ↑로 닿습니다. |
| 기타 7 | 켬·끔 행을 클릭하면 그 행을 고르기만 합니다. 값은 켬·끔 글자, ‹ ›, ←→, Enter로만 바뀝니다. |
| 새 피드백 3 (스킨이 되돌아감) | 곡 선택의 새 패턴 만들기는 채보가 끝나면(Mapperatorinator로 몇 분) 패턴을 설정에 적었는데, 그때 곡 선택 화면이 떠날 때의 설정을 통째로 저장해서 그사이 바꾼 스킨 · 설정이 되돌아갔습니다. 이제 await 뒤의 변경은 App의 최신 설정에 적용됩니다(`SettingsChange`: 새 설정, 또는 최신 설정을 바꾸는 함수). 같은 꼴이던 곡 추가 · 채보 가져오기 · 곡 삭제 · 저장 채보 삭제 · 없어진 채보 정리도 함께 고쳤습니다. 회귀 테스트: `e2e/settingsLatest.spec.ts`. |
| 새 피드백 5 ('대기' 없음) | 채보를 만들 때 차례를 기다리는 다른 난이도 판에 '대기'를 보이지 않습니다. 만들고 있는 판 하나만 '생성 중'입니다. |
| 새 피드백 6 ('생성 중'이 사라짐) | 플레이어가 만들게 한 채보의 '생성 중' 표시를 곡 선택 화면이 아니라 화면을 넘어 남는 채보 저장소(`chartStore`)에 둡니다. 곡 선택으로 돌아오면 아직 만들지 않은 채보의 판 정보를 서버에 한 번 다시 묻고, 만드는 중이면 5초마다 계속 묻습니다. 설정 · 결과 화면을 거쳐 와도 '생성 중'이 남는 것을 e2e로 확인합니다. |
| 기타 9 | 곡 선택의 커버 크기를 고정했습니다(1280×720에서 256px). 판 아래 표시 줄이나 두 줄짜리 안내가 생기면 커버가 줄던 것이 원인이었습니다. 가져오거나 편집한 채보가 있는 키 모드에서만 한 줄이 더 생겨 커버가 작아집니다. |

## 남은 것

- 서버 응답 변화(기존 생성기 삭제, 늘 모델의 박자 쓰기)는 세션 3이 맞춥니다. `client/src/api/client.ts`의 `MapperSettings.enabled` · `useAppTiming`은 화면에서 쓰지 않지만 형식은 그대로 두었습니다.
- 곡 설정의 "첫 박 위치" · "BPM 보정"은 채보가 모델의 박자만 쓰게 되면 채보에 닿지 않습니다. 세션 3의 변경 뒤 남길지 정해야 합니다.
- 곡 선택의 "새 패턴 만들기"(F5, 메뉴)는 그대로입니다. 결과 화면에서만 뺐습니다.
- 키음 설정과 스템 관련 화면은 그대로입니다(스템 분리를 남길지 정하는 중).
- e2e: `select.spec.ts` · `tiers.spec.ts`(24개 중 23개), `phase1.spec.ts`, `phase3.spec.ts`의 두 테스트는 develop(b8747dc)에서도 실패합니다. 새 화면 디자인 전의 화면을 가정한 것이 많아 따로 고쳐야 합니다.
